# Advanced Analytics Upgrade

This upgrade moves the case study beyond basic KPI queries toward an analyst-ready portfolio project.

## Added capabilities

- **RFM customer segmentation:** Recency, Frequency and Monetary scoring with actionable segments such as Champions, Loyal, At Risk - High Value and Churn Risk.
- **Cohort retention:** First-purchase cohorts tracked by months since acquisition.
- **Revenue growth analytics:** Monthly revenue, MoM change, MoM growth percentage and cumulative revenue using window functions.
- **Data quality controls:** Referential integrity checks, invalid quantity/discount checks, missing line-item checks and revenue reconciliation.

## Business value

The project can now answer not only **what happened**, but also:

1. Which customers deserve retention investment?
2. How well are newly acquired customers retained?
3. When did revenue growth accelerate or deteriorate?
4. Can management trust the underlying dataset?

## Recommended next upgrade

Add a Power BI executive dashboard connected to the same SQL model, with KPI cards, revenue trends, customer segments, cohort retention and drill-down filters.
